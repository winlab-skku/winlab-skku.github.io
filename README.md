# WIn Lab website

Wireless Intelligence Lab, Sungkyunkwan University — https://winlab-skku.github.io/

This repository holds the published site (`docs/`, served by GitHub Pages: Settings → Pages → Branch `main`, Folder `/docs`)
and the admin tool that edits and deploys it.

## 사이트 수정하는 법

1. 이 저장소를 PC에 받습니다 (처음 한 번: Code → Download ZIP → 압축 풀기).
2. `WInLabAdmin.exe`를 더블클릭합니다. (Python이 있으면 `python admin.py`도 됩니다.)
   - 실행할 때마다 GitHub에서 최신 버전을 자동으로 받아옵니다. 다시 내려받을 필요가 없습니다.
3. 브라우저에 뜬 관리자 화면에서 수정 → **저장 + 빌드** → 미리보기로 확인.
4. **GitHub에 배포**를 누르면 바뀐 파일이 바로 저장소에 올라가고, 1~2분 뒤 사이트에 반영됩니다.
   - PC마다 처음 한 번 **GitHub 배포** 탭에서 토큰을 연결해야 합니다 (화면의 안내를 따라 1분이면 됩니다).

### 논문 목록을 교수님 CV와 맞추기
교수님 CV 사이트(https://sites.google.com/view/kisonglee/publications)가 논문 목록의 원본입니다.
관리자 화면 **Publications** 탭 맨 위의 **CV에서 가져오기**를 누르면 CV를 읽어서 새 논문 · 바뀐 논문 · 빠지는 논문을
먼저 보여주고, **CV 내용으로 바꾸기**를 누르면 목록이 CV와 똑같아집니다. 그다음 저장 + 빌드 → GitHub에 배포.
(CV에 없는 수정은 덮어써지므로, 논문 정보 수정은 CV에서 하세요. 자동으로 안 읽히면 CV 페이지 내용을 복사해서 **직접 붙여넣기**.)

### 같이 수정할 때
- 배포하지 않은 내 변경은 실행·최신 받기를 해도 그대로 남습니다.
- 다른 사람이 **같은 파일**을 먼저 배포했다면: 배포가 거절되고 아무것도 바뀌지 않습니다.
  **최신 받기**를 누르면 GitHub 버전으로 맞춰지고 내 버전은 `_backup/<시각>/`에 보관되니, 다시 입력해서 배포하세요.
- 다른 파일을 고쳤다면 배포할 때 자동으로 합쳐집니다.

## Structure
```
docs/                    the website (generated by build.py — do not edit by hand)
data/site.json           members, alumni, news, research areas, site text, settings
data/publications.json   publication list
docs/assets/photos/      member photos (<english-name-lowercase>.jpg, auto-resized on build)
build.py                 turns data/ into docs/
admin.py + admin/        local editing page + GitHub sync/deploy
launcher.py              entry point of WInLabAdmin.exe (runs admin.py/build.py from this folder)
make-exe.bat / .sh       builds WInLabAdmin.exe (needs Python once)
```

Local only, never uploaded: `.sync-state.json` (which GitHub version this folder matches), `_backup/`,
and the token (saved in `%APPDATA%\WInLabAdmin\`, outside this folder). `*.exe` files are not synced or deployed;
upload a new `WInLabAdmin.exe` through the GitHub web page if you rebuild it.

## When to rebuild WInLabAdmin.exe
Almost never: the exe runs `admin.py` and `build.py` from this folder, so updates to those arrive with the
automatic sync. Rebuild (double-click `make-exe.bat`) only if `launcher.py` changes or the tools start using a new library.
